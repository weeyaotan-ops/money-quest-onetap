# Money Quest Safe One-Tap Helper

- Clean mobile ticket page for Telegram.
- Shows symbol, side, Entry, SL, TP, contracts, leverage, margin, equity, target risk, actual max loss, and risk utilization.
- Includes **Copy full ticket** and **Open OKX**.
- Does not submit orders or use OKX API keys.
- Final order confirmation remains manual.
